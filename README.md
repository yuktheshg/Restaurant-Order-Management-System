# Restaurant Order Management System

## Project Overview
The Restaurant Order Management System is a database project developed using MySQL. It manages restaurant operations, including customer details, menu items, orders, order details, and payments.

## Objectives
- Store and manage customer information.
- Maintain restaurant menu items and prices.
- Track customer orders and their statuses.
- Manage payment details.
- Generate useful reports using SQL queries.

## Technologies Used
- MySQL
- MySQL Workbench
- Visual Studio Code

## Database Tables
1. Customers
2. Menu
3. Orders
4. Order_Details
5. Payments

## SQL Concepts Implemented
- Database and table creation
- Primary keys and foreign keys
- INSERT, UPDATE, DELETE and SELECT
- WHERE, ORDER BY and LIMIT
- Aggregate functions
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN and RIGHT JOIN
- Subqueries and Common Table Expressions (CTEs)
- Views
- Stored Procedures
- Triggers

## Key Features
- Customer and menu management
- Order tracking
- Payment status monitoring
- Revenue analysis
- Food price validation using a trigger
- Customer order retrieval using stored procedures

## How to Run
1. Open MySQL Workbench.
2. Execute `database.sql` to create the database.
3. Execute `tables.sql` to create the tables.
4. Execute `insert_data.sql` to insert sample data.
5. Execute `queries.sql` to explore SQL operations.
6. Execute `views.sql` to create views.
7. Execute `stored_procedures.sql` to create stored procedures.
8. Execute `triggers.sql` to create triggers.
